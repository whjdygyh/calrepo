# 中国传统及公共假日源完整性审计

- 作者：林建木
- 日期：2026-07-25
- 状态：强制法定项已实施；传统候选待审核
- 范围：`SRC-CN-TRADITIONAL-PUBLIC`

## 结论

当前节日总表不能称为完整的“中国传统及公共假日”源。此前只按七类国家法定节日做了最低检查，遗漏了自 2025-01-01 起纳入春节法定假期的除夕；也遗漏了两个依法属于部分公民放假日的妇女节和建军节。

更根本的问题是：现有表只有“节日日期规则”，没有独立记录假日性质、法定天数、适用对象和年度调休。春节、劳动节、国庆节等多天法定假期不能只以单日节日名称代替；每年的连休与调休必须来自国务院办公厅年度通知，不能由固定规则推断。

审计后的强制修正已写入基准表：8 个全体公民法定事件、4 个部分公民放假日，以及节日性质、适用对象、法定休假天数、年度安排类型四个独立字段。传统文化候选项仍保留在本报告中，待完成规则和范围审核后再入源。

## 已有内容

### 国家法定节日

已存在：元旦、春节、清明节、劳动节、端午节、中秋节、国庆节。

缺口：除夕。国务院 2024 年修订、2025 年起施行的《全国年节及纪念日放假办法》将春节假期调整为农历除夕、正月初一至初三，共四日。因此数据至少应有 `除夕(法)` 与 `春节(法)` 两个可显示事件；假期天数与调休另建字段/年度安排数据。

### 部分公民放假日

现有：五四青年节、儿童节。

缺口：妇女节、建军节。国务院规定妇女节为妇女放假半日，青年节为 14 周岁以上青年放假半日，儿童节为不满 14 周岁少年儿童放假一日，建军节为现役军人放假半日。它们不是“全体公民法定假日”，不能使用 `(法)` 与元旦、春节等混为同一性质。

### 全国性传统节日

现有固定农历规则：除夕、春节、元宵节、龙抬头、上巳节、端午节、七夕、中元节、中秋节、重阳节、腊八节。

确认需要补充研究：

| 节日 | 建议 | 原因 |
| --- | --- | --- |
| 寒食节 | 纳入候选 | 与清明节相邻但并非固定农历日；需要新增相对节气规则并核验日期口径。 |
| 下元节 | 纳入候选 | 农历十月十五，日期规则明确，文化覆盖面应先确认后发布。 |
| 小年 / 祭灶 | 不作为全国单一事件 | 北方多为腊月二十三、南方多为腊月二十四；必须按地域变体分别建模。 |
| 冬至、清明 | 不重复建传统事件 | 已由“二十四节气”源提供天文日期；清明的法定假日属性可在公共假日源另列。 |

### 固定公共纪念日

现有：植树节、五四青年节、儿童节、中国共产党成立纪念日、中国人民抗日战争胜利纪念日、教师节、烈士纪念日、国庆节、国家宪法日。

需要建立“国家设立纪念日候选池”并逐条定范围，不能把联合国国际日或商业节日混入中国主源。优先待核项目包括中国人民警察节、全民国家安全教育日、全国防灾减灾日、中国旅游日、全国科技工作者日、全国生态日、中国医师节、中国农民丰收节、国家公祭日等。其中中国农民丰收节按秋分附近择日，不能按固定公历日建模。

## 建议的数据模型

保留节日总表的一行一节日规则，同时增加以下原子字段：

| 字段 | 示例 | 用途 |
| --- | --- | --- |
| `节日性质` | 传统节日 / 全体公民法定假日 / 部分公民放假日 / 国家纪念日 | 不再依靠名称后缀判断属性。 |
| `适用对象` | 全体公民 / 妇女 / 现役军人 | 表达部分公民放假的法定范围。 |
| `法定休假天数` | 1 / 2 / 3 / 4 / 0.5 / 空 | 记录法律规定的基础天数，不记录当年拼假。 |
| `年度安排类型` | 固定日期 / 需国务院年度通知 | 明确哪些事件必须逐年维护。 |
| `源编号` | SRC-CN-TRADITIONAL-PUBLIC | 已存在，作为与源目录的稳定关联。 |

需要独立的“年度放假与调休安排”数据表：一行一具体日期，记录年份、日期、事件、是否放假、是否调休上班、国务院通知链接和核验状态。它不能混进节日规则总表，否则固定规则和年度例外会互相污染。

## 必须立即处理

1. 将当前法定集合由 7 条改为 8 个可显示事件：补 `除夕(法)`。
2. 补妇女节和建军节，并标记为“部分公民放假日”，不标 `(法)`。
3. 将法定集合验收规则由“七项”改为“八个可显示事件 + 假日天数/年度通知校验”。
4. 新增假日性质、适用对象、法定休假天数、年度安排类型字段。

## 不纳入本轮

- 港澳台及地方性放假安排：需单独适用范围和来源。
- 少数民族节日：按既有民族源逐项研究，不塞入全国中国主源。
- 联合国国际日、商业促销日和全球世俗节日：保留在各自独立源。
- 小年等存在明确地域差异的节日：先建立变体和地域模型。

## 依据

- 《全国年节及纪念日放假办法》（国务院令第 795 号，2024 年修订，2025-01-01 起施行）：国家法定节日、春节含除夕、部分公民放假日。
- 国务院办公厅年度部分节假日安排通知：每年连休、调休上班日和实际放假跨度的唯一发布依据。
- 中国气象局二十四节气资料：节气天文规则的公开参考；清明、冬至等不应写死为固定公历日。
